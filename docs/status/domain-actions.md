# domain:actions

Package `io.github.lenticualrstone.civilight.domain.actions` (pure Kotlin JVM; depends on every domain module, see `domain/actions/build.gradle.kts`). The one write path for user actions that span several rule modules (DECISIONS §1). No I/O, no clock: every action takes an `ActionContext` (now, zone, device, key source) and returns the next `ProjectDoc` (and the recorder library or trash state where it changes) plus what the UI shows (toast, report, undo pair).

## Defaults used

- Scene delete stores the scene's reference sites (`TrashOps.REF_SITES`) as read **before** the 때 rebase, so the restore report counts the rebased `기준` links as re-linked (`relinked[BASE_SCENE]`), not as `그대로 둔 것`.
- Scene restore report `name` = the scene title (as `RestoreOps` names units); the toast wording for scenes is the caller's (no spec copy for a scene restore toast).
- `CharacterActions.delete` returns null for an unknown or already trashed character; `purge` returns null when the character has no trash entry.
- Character restore toast: the cast report (`DeletedItems.restoreReport`) when the entry has a cast snapshot, else `Messages.restoreToast` (entries written before this module, merged entries).
- Merge: the character-only cells (`소개 · 표시 이름 · 태그 · 말투 · 비밀`) follow CST-45 like fields: target-empty ones are filled, others only when chosen; a taken `표시 이름` brings the merged item's `표시 이름` records (same-point clash rule). Chosen character-only cells are recorded as `MergeChoice(ext = {"cell": "<property>"})`; `ext.summary.fields` counts them (restore sheet `칸`).
- Merge undo of recorder links is row-level by link key (links the merge changed or dropped come back; later edits of other links stay).
- Purge: a whole project's links take the 서재 row's name (else the document's) and `hidden` = row or project hidden. Item purges run on every project document given (live or trashed) except those purged whole in the same run. Blob candidates include everything a purged project held; "held" = the asset index plus image uses, script assets, map base images and sketch photos (live or trashed rows), and kept recorder audio.
- Plain unit label for recorder links = `domain:story` `UnitCodes(before).unitLabel` (`1-7 씬 3`, `1-7`, `1장`), per DECISIONS §1 (domain code uses `UnitCodes`).
- CSV: `블록 ID` of a spoken option = the choice block key (as `DialogueCsvExport` writes it); `(…)` parentheticals written (SCR Q-10); voice column empty while voice IDs are off; transition rows have no state (LIB-44 `ED`); `버림` rows are the plan's discarded IDs.
- JSON `characters[].displayName` = the script's value (display name at the speaker's first written line) when present, else `displayNameBase` or the name.
- Distance tolerance 1 m (`domain:story` rounds to metres).

- **domain:library**: `CsvRows.voiceIdFor` (used by `VoiceFixation`) takes any `manualId`, while `domain:script` `VoiceIds.currentId` uses `manualId` only when the project's voice-ID format is `직접`.
