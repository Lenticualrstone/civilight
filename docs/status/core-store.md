## Partial

- **Undo history is in memory only** (per open `ProjectStore`, cleared when the store closes). `_app/undo/` persistence (optional in §8.2) is not written.
- **Purging rows inside a project** (trashed scenes, characters … after 30 days, name tags, deletion log) is domain work over `ProjectDoc` (domain:trash); the store purges whole projects and recorder records only. `runMaintenance` does not open projects to purge their inner rows.
- **Project rows `lastLabel` on purge**: `markProjectPurged` labels only `project` links with the project name; links to units, characters … of a purged project keep the label they had (null if none). Resolving item names is recorder-domain work.
- **`flushAllBlocking` / `onStop`**: the store has no lifecycle dependency; the app must call `StoreContainer.flushAll()` (or the blocking form) from `onStop`. `TRIM_MEMORY_UI_HIDDEN` is only a safety net.
- **Maintenance is not scheduled by the store**: the app must call `StoreContainer.runMaintenance()` at start and daily (LIB-39 `ED` WorkManager job; WorkManager is not a dependency of this module).
- **Recovery of a crash inside `moveAsideForImport`** leaves an extra copy (never a lost one); there is no dedicated roll-forward for it.

## Defaults used

- Store layout: `files/projects/<key>/`, `files/trash/projects/<key>/`, `files/trash/index.json` (trash rows of kind `project`; rows inside a project stay in its own `trash/index.json`, recorder rows in `files/recorder/trash.json`), `files/library.json`, `files/recorder/{records,trash,store,session,draft}.json`, `files/blobs/<sha256>.<ext>`, `files/app/{onboarding,recents}.json`, `files/device-id`, DataStore `settings`.
- Project directory app files: `_app/store.json` (store version), `_app/damaged/<UTC time>/` (set-aside files), journal `.commit-journal.json`, temps `.<name>.<tag>.civilight-tmp`.
- Recorder audio goes into the one global blob store (source `recorder`), not a separate recorder folder (§2.10 "one global blob store on the device").
- Save timing: 600 ms debounce, 3 s maximum delay; undo cap 100 steps; typing merge window 2 s; blob grace period 24 h before garbage collection (a just-imported, not yet referenced image is kept).
- Blob garbage collection deletes nothing while any project cannot be read completely (a damaged file at load, anything under `_app/damaged/`, a directory reconcile could not read) or a set-aside recorder file exists, since their missing rows may still name blobs. Importing bytes that are already stored restarts their grace period.
- Blob references are `ImageUse`, `ScriptAsset.fileHash`, `WorldMap.baseImageHash`, `MapSketch.photoHash` and recorder audio, live or trashed. `assets.blobs` index rows are metadata, not references (§5.3), so the trash/CNV domain should drop index rows of blobs nothing uses.
- 서재 order: `LibraryEntry` has no order field; `LibraryState.live` sorts by `updatedAt` descending (LIB-01 `ED` "sorted by last modified"). `updatedAt` of an index row = time of the last content edit; `lastOpenedAt` = last `open`.
- Name rules: NFC + trim, blank refused; `nextFree` strips an existing ` (n)` and takes the smallest n ≥ 2 not used by any project row (live or trashed).
- `duplicate`: not offered for the example project; trashed rows inside the project are copied with it; app state starts empty. Copy is not hidden unless `project.json` says so.
- Purge date: `TrashEntry.purgeDateFor(local date of deletedAt in the clock's zone)`; purged when `today ≥ purgeOn` (T-08).
- Settings are one JSON string preference (`appSettings`) encoded with `CivilightJson`; unreadable or missing → defaults; unknown keys dropped; unknown closed-enum values fall back.
- Index rows follow `project.json` name, rating and `protections.hidden` on every content edit through a `ProjectStore` (also on undo).
- An unknown file path that collides with a layout path or `_app/` is not written (never overwrites a known unit).
- A damaged `library.json`, `trash/index.json`, recorder file or app file is renamed `<name>.damaged-<millis>` and the store starts from what the directories say (library) or empty (others).
