## Architecture

**Entries.** `StoryEntries.kt` (`@file:JvmName("StoryEntries")`, `storyEntries(deps)`, shell.md §1) registers the following.
- Routes: `ProjectHome`, `StoryStructure`, `SceneNotationSettings`, `CheckCenter`, `ProjectSearch`, `DayBandSettings`, `BulkPlaceTime` (batch 4), `LibrarySearch` (batch 4). Every story route is registered now.
- Shared sheets (owner STORY), all four now: `UnitMenuSheet`, `NewUnitSheet`, `SceneWhereSheet`, `SceneMoveSheet`.
- Feature-local sheets registered in the `SheetRegistry` (so they open over any host, the script included): `CascadeSheet` (`때 바꾸기` started outside the `장소와 때` sheet), `MoveTargetSheet` (the `옮기기` destination picker).
- Opened, not registered: SCRIPT's shared `RenumberSheet(p, episodeKey)` (episode ⋯ `번호 다시 매기기`, search command) and `SceneMergeSheet`; SHELL's `LensSheet`. The local renumber key, its content and `RenumberModelTest` were removed in batch 3 (script lane request).

Local to one screen (in its `localSheets`, saved with it): `BulkPlaceSheet`, `BulkWhenSheet` (bulk screen), `PickSpeakerSheet` (점검 센터).

**How to extend** (next batches):
- **New screen:** add a package with `XCopy`, `XModel` (pure, tested), `XViewModel : StoryViewModel(projectKey, services)` and `XScreen(route, deps)`. Create the view model with `entryViewModel { XViewModel(route.projectKey, deps.storyServices()) }`. Wrap the screen in `CenterColumn { CivilightScreen(…) }`. Hide the back button when `LocalPaneRole.current == PaneRole.DETAIL`.
- **New edit:** write a pure function (in `StoryActions` or the screen's model) that returns the new doc, or the same doc when its precondition no longer holds. Call it through `apply(label)`. Scene structure and time edits go through `domain:actions` `SceneActions`; never call `domain:script` `SceneSplit` / `SceneMerge` / `SceneLifecycle`.
- **Shared sheet (STORY):** register it in `storyEntries` with `deps.sheets.register<K> { sheet -> KContent(sheet, deps) }`. Inside the content, read the host's store via `currentProjectStore`, take edits from `storyActions(projectKey, deps)`, and start with `SheetHeader`. Swap to another sheet with `close()` + `open(next)` (`replaceWith` in `MenuSheets.kt`).
- **Menu rows:** add a `MenuAction`, a row in `UnitMenuModel` / `StructureMenuModel`, and its branch in `UnitMenuContent`. Rows whose label is a `TODO_COPY_…` constant are dropped by `MenuModel.drawnOnly()` and appear by themselves once the constant gets words.
- **Copy:** add every new `…Copy` object to `StoryCopyLintTest.copyObjects`, and button constant names to its `buttons` set. Never put a `TODO_COPY_…` value on screen (`isDrawnCopy`, `HomeStartModel.shownSub`).
- **A field typed into:** keep the draft in `rememberSaveable` in the composable (Hangul composition) and save with `StoryViewModel.applyMerged(label, mergeKey)`, so one typing run is one undo step.
- **Cross-module edits from a screen:** add a `FixEffect`-style sealed result in the screen's model (see `check/CheckFixes.kt`) and test it on the JVM; composables only dispatch.
- **A `되살리기` with its toast:** return a `RestoreStep(doc, change, toast)` from a pure function and call `restoreWithToast(label) { d, ctx -> … }` (see `PlaceFix.restoreStep`, `CastModel.restoreStep`, `CheckFixes.restoreStep`).
- **Hand-over between screens without a route argument:** `deps.results.send(key, value)` before `push`, consumed once in `rememberSaveable` by the target (`BulkModel.preselectKey`). Ask core for a route argument when it becomes permanent.
- **A schematic map:** build a `MiniMap` with `MiniMaps` (pure) and draw it with `MiniMapView`.
