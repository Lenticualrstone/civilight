# 0.1.1 backlog (deferred from 0.1.0 emulator QA, 2026-11-23)

Rule: only critical issues block a release; anything that can hurt usability counts as critical. These were judged cosmetic and moved here.

- [feature:library] 서재 목록→카드 전환 중간에 '프로젝트 · 1' 라벨과 라이프 레코더 구역이 몇 프레임 사라지고, 'M' 글자가 이전·새 썸네일로 두 겹 보임
- [feature:cast] 인물 목록→카드 전환 중 두 모드에서 똑같은 목록/관계도 세그먼트, '전체 2' 칩, 태그 라벨까지 약 40%로 어두워졌다 돌아옴(목록만이 아니라 본문 전체를 크로스페이드). 아바타도 프레임 03~04에서 두 겹.

- [feature:canvas] 캔버스 확대 버튼에서 뷰포트는 움직이지만 '%' 라벨은 첫 프레임에 125%로 바로 바뀜(감사 §4 canvas #1은 P4 ValueSwap)
- [feature:canvas] 보기 전환(목록↔격자↔카드)은 약 120–150 ms 크로스페이드뿐임. GAL-24의 썸네일 morph(CNV-45, 360 ms)는 없음(공유 요소는 뷰어 열기에만 적용). 정적 컷은 아님.
- [feature:canvas] `옮기기` → `이 뒤로` 때 행이 새 자리로 미끄러지지 않고, 모드가 끝나며 목록 전체가 크로스페이드됨. 중간 프레임에 이동 전/후 목록의 버튼 글자(`이 뒤로`/`앞으로`)가 겹쳐 보이고, 첫 프레임에서 이동 행이 아직 2번째 자리에 있으면서 번호가 이미 '5'로 바뀜.
- [feature:canvas] 격자 보기에서 숨긴 항목이 GAL-06/T-GAL-06의 마지막 '숨긴 이미지' 타일이 아니라 가로 전체 LockRow로 표시됨(프로젝트 갤러리 그룹 상태). 카드 보기도 같은 행.
- [feature:canvas] `순서 바꾸기` 화면 행에 GAL-15의 손잡이(grip, `끌어서 옮기기`)가 없음. 끌어서 옮기기 불가. 버튼과 `옮기기`로는 이동할 수 있음.
- [feature:canvas] 추가 시트가 닫히는 동안 한 프레임에 방금 넣은 타일이 번호 배지와 `이미 있음`을 함께 보이고 `넣기 · 0`이 활성 색으로 남음(닫기 전에 상태를 다시 계산).
- [feature:canvas] 설명 판의 `더 보기`/`접기` 글자가 본문 시작선보다 약 20 px 안쪽에 있음(버튼 내부 패딩).
- [feature:story] '목록 닫기' 때 통계 줄(0/1 · 오늘 쓴 글자 · 인물)이 한 프레임 만에 전체 높이로 끼어들어, 바로 쓰기와 시작해 볼 것 블록이 약 120px 아래로 한 번에 밀린 뒤 위로 올라감. 끼어드는 통계 항목에 높이 펼침이나 위치 이동 애니메이션이 없어 보임(10x에서 pre→f11 약 0.6초, 실제로는 약 60ms 안에 전부 바뀜).
- [feature:library] 온보딩 워크스루 1/3 '밀어서 탭 고르기' 데모에서 닫힌 상태에도 블록 오른쪽 끝에 약 32px(12dp) 버튼 바탕 띠가 보임. 블록 Column 폭은 350dp로 고정인데 카드 안쪽 폭은 약 362dp라서, 뒤의 버튼 줄이 드러남.
