Rule: only critical issues block a release; anything that can hurt usability counts as critical. 0.2.3 shipped with no emulator run; everything below was found or left in the code review and view-kind code check.

- [feature:canvas] Empty gallery preview (no images): the 보기 고르기 preview has no state of its own for a gallery with zero images, and no board draws one. Draw it from a board or show the view's own empty state.
