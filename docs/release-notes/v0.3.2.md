# Civilight 0.3.2(Antigravity) · Atelier 서재 보기 10종 전면 개편

기존 0.2.x 서재 보기 13종을 모두 폐기하고, **"야간 원고" 미학에 맞춘 차세대 3D·모션·프로시저럴 렌더링 서재 보기 10종(Atelier)**으로 전면 교체했습니다.

> 이번 버전의 축: **공간 · 3D 5종** · **모션 · 작업 5종** · **실시간 반사광·자이로·스프링 물리** · **기존 설정 무손실 마이그레이션**

## 새로운 서재 보기 10종

### 공간 · 3D (5종)
1. **유리 프리즘 (`GLASS_PRISM`, 기본값)**: 3D 다면 프리즘 회전 캐러셀 + 각도·기울기 연동 실시간 반사광(Specular Sheen)
2. **깊이 서고 (`ARCHIVE_VAULT`)**: `Canvas` 소실점 3D 원근 건축 격자 + 세로 드래그 Z축 깊이 부상
3. **양장 서가 (`BOOK_SPINE_3D`)**: 프로시저럴 3D 양장 책등(원통 조명 · 금박 띠 · 선반 그림자) + 선택 시 2단계 스프링 꺼내기 및 표지 회전
4. **궤도 무대 (`ORBIT_STAGE`)**: 기울어진 3D 타원 공전 궤도(`zIndex` 깊이 정렬) + 궤도 눈금 및 전경 스포트라이트
5. **화첩 펼침 (`FOLIO_SPREAD`)**: 좌측 제본 축(`TransformOrigin(0f, 0.5f)`) 기준 3D 페이지 젖힘 + 90° 접힘 그림자

### 모션 · 작업 (5종)
6. **탄성 덱 (`KINETIC_DECK`)**: 깊이별 시차 스프링 강성(Staggered Spring Whip)으로 후행 카드가 탄성 있게 따라오는 부채꼴 덱
7. **모자이크 (`BENTO_MOSAIC`)**: Z 폴드 8 커버(2열)/내부(3열) 반응형 에디토리얼 벤토 격자 + 히어로 카드 + 탭 시 스프링 인라인 포커스
8. **필름 릴 (`FILM_REEL`)**: `Canvas` 35mm 필름 스프로킷·프레임 번호(`01A`) + 스크롤 시 프레임 내부 광학 패럴랙스
9. **시간 축 (`PULSE_TIMELINE`)**: 활성 노드의 호흡하는 맥동(Pulse) 링 애니메이션 + 세로 작업 연대기 및 진행 막대
10. **스튜디오 목록 (`LIST`)**: 300 dp 투페인과 커버 화면에 최적화된 모션 작업 목록(기울기 썸네일 · 슬라이딩 강조 막대 · 진행 헤어라인)

## 호환성 및 안전성
- 이전 버전(0.3.1 이하)에서 저장된 옛 보기 이름(`bookshelf`, `timeline` 등)은 앱 실행 시 자동으로 기본값(`유리 프리즘`)으로 안전하게 전환됩니다.
- 모든 10종 보기는 숨긴·잠긴 프로젝트 마스킹, `애니메이션 줄이기`(모션/루프 해제), `보기 고르기` 실시간 미리보기, Z 폴드 8 커버/내부 세로/내부 가로 화면을 지원합니다.
