# Civilight 0.6.1(Antigravity) (Pre-release)

> 0.6.0(Antigravity)에서 확인된 폴드 펼친 화면 레이아웃 부조화·몰입 상세 스크롤 물리·숨김 프로젝트 노출 문제를 전면 정비하고, 서재 `가로 스와이프` 보기와 설정 화면 버전 표시를 추가한 업데이트입니다.

## 주요 개선 및 새 기능

### 펼친 화면 `서재`·`작품 홈` 전용 레이아웃 및 전환 개선
* **스플릿 분리**: `서재`와 `작품 홈`을 `목록 + 상세` 2분할 쌍에서 분리해, 하위 화면(`원고`, `인물`, `세계`, `연표`, `점검`)으로 이동할 때 스플릿·미니레일 재생성으로 발생하던 버벅임과 화면 점프를 해소했습니다.
* **작품 홈 적응형 스튜디오 레이아웃**: 펼친 가로 화면(`≥ 840dp`)에서는 `2 : 1 : 1` 3열 배치(작품 표지·바로 쓰기/이어 쓰기·체크리스트 / 현재 장·에피소드 / 작업 허브), 세로 펼친 화면(`600–839dp`)에서는 상단 아이덴티티 카드 + 2열 배치로 여백 낭비를 없앴습니다.

### 몰입 상세(`ImmersiveDetailScaffold`) 물리·시각 개편
* **타이틀 ↔ 본문 패널 1:1 속도 동기화**: 도킹 스크롤 거리(`D = panelStartY - headerHeight`)와 타이틀 이동 곡선을 일치시켜, 타이틀이 급발진하거나 헤더 아래 큰 공백이 남지 않고 본문 패널과 정확히 동시에 안착합니다.
* **스프링 디텐트 텐션감**: 히어로 ↔ 도킹 전환 구간에 방향성 히스테리시스 + 플링 기반 스프링 스냅(`hingeTension`)과 햅틱 틱을 추가했습니다.
* **하단 풀블리드 및 셰이드·가독성 수정**: 2분할 상세 화면의 하단 수평 절단을 해소하고, 스크롤 시 검정 하단 셰이드를 `heroSource` 바깥에서 `1 → 0` 완전 페이드 아웃하며 패널 가독성(라이트 `.80 → .90`, 다크 `.74 → .86`)을 높였습니다. 표지 이미지가 없을 때는 과한 회색 그라데이션 대신 테마 톤과 `ink` 글씨를 적용합니다.

### 패널 열기/닫기 버튼 통일 & 경계 클리핑
* **단일 앵커 토글**: 경계선 위 `<` 배지를 제거하고, 열림·닫힘 모두 동일한 `IconId.Panel` 아이콘·`44dp` 크기·동일한 외곽 상단 고정 좌표로 통일했습니다.
* **패널·스테이지 클리핑**: `SplitLayout` 양쪽 패널과 아틀리에 3D 스테이지에 `clipToBounds()`를 적용해 카드가 경계를 넘지 못하도록 차단했습니다.

### 숨긴 프로젝트 서재 완전 비노출 & 설정 전용 보관함
* **서재 완전 비노출**: 서재 목록·카드·3D 뷰에서 자물쇠 카드/행 및 `· 숨김 M` 개수 표기를 완전히 제거하고, 설정 목록에서도 인증 전에는 숨긴 프로젝트 개수를 노출하지 않습니다.
* **`설정 › 보관 · 보안 › 숨긴 항목 보기` 신설**: 생체/기기 잠금 인증 후에만 숨긴 프로젝트 목록을 확인하고 열기·숨김 풀기·관리·다시 잠그기를 수행할 수 있습니다.

### 원고 화면 정렬 · 서재 `가로 스와이프` · 설정 버전 표시
* **원고 본문 중앙 정렬**: 사이드 패널이 닫힌 넓은 화면에서 본문 열(최대 `640dp`)을 수평 중앙 정렬하고, 닫힌 미니 레일의 불필요한 탭 활성 표시를 정리했습니다.
* **서재 `가로 스와이프` 보기 추가**: 표준 `HorizontalPager` 기반의 자연스러운 좌우 스와이프 카드 보기를 추가했습니다.
* **설정 버전 표시**: 설정 첫 화면 하단 및 `관리 · 지원`에 현재 앱 버전(`Civilight 0.6.1(Antigravity)`)을 표시합니다.
