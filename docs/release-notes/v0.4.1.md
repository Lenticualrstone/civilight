# Civilight 0.4.1(Antigravity)

`0.4.1(Antigravity)`는 `0.4.0(Antigravity)` 이후 발견된 기능 접근성 및 사용성 회귀를 즉시 보완한 패치 릴리즈입니다.

## 주요 수정 사항

* **인물 초상(`인물 포트레이트`) 상시 노출 & 바로 탭**: 초상이 비어 있는 캐릭터에서도 `빈 항목 보기`를 켜지 않고 바로 `인물 초상` 항목에서 포트레이트와 홀로그램 효과를 설정할 수 있도록 변경했습니다. 프로필 상단 초상화 자체를 탭해도 바로 이미지 선택 시트가 열립니다.
* **홀로그램 효과 스위치 상시 표시**: `이미지 고르기` 시트에서 타일 목록 맨 아래에 숨어 있던 `홀로그램 효과` 스위치를 스크롤 영역 밖(하단 버튼 바로 위)으로 고정해 스크롤 없이 즉시 확인·전환할 수 있습니다.
* **여러 프로젝트 내보내기 진입점 복구**: `0.4.0`에서 서재 상단바를 3버튼(`[보기 ▾] [+] [⚙]`)으로 정리하며 빠졌던 `여러 프로젝트 내보내기` 진입점을 서재 하단 포커스 독(`내보내기`)으로 깔끔하게 복구했습니다.
