# Civilight 0.7.2(Antigravity) (Pre-release)

> 스크립트 본문 블록, 장면 전환, 상단 플롯 타임라인을 실제 **Sonnet-Create 스타일 레이아웃**으로 전면 교체한 프리릴리즈입니다.

## 주요 개선 사항

### Sonnet-Create 스타일 원고 블록 레이아웃
* **대사 블록**: 초상 아래에 좁게 깔리던 이름 대신 **좌측 초상 + 우측 상단 화자 이름(강조색, semibold) + 바로 아래 대사 본문** 구조로 배치했습니다. 동일 화자 연속 대사 시 초상·이름을 생략해 자연스럽게 이어집니다.
* **지문 블록**: 좌측 여백 없이 **중앙 정렬 · 이탤릭** 무대 지시문(최대 `480dp`, 뮤트 톤)으로 배치해 대사와 한눈에 구분됩니다.
* **`//` 주석 메모 · 연출 · 시스템 블록**: 좌측 56dp 거대 배지 박스를 제거하고 중앙의 조용한 모노 주석 캡슐(`// 내용`) 및 경량 지시문(`✦ ...`)으로 정리했습니다.

### 첫 장면 헤더 제거 & 장면 전환 구분선
* **첫 장면(`씬 1`) 헤더 제거**: 상단의 불필요한 `씬 1 · 장소 없음 · 때 없음 / 전환 문구 · 없음` 헤더를 없애고 본문이 바로 시작되도록 정리했습니다.
* **장면 전환 블록(`2번 씬`부터)**: `[ 장면 ]` 탭이나 `---`로 추가한 장면 전환을 제목이 있을 때는 **`──── [ 제목 ] ────` 중앙 모노 캡슐 칩**, 제목이 없을 때는 **얇은 `1dp` 가로 구분선**으로 표시합니다. (탭 = 장소·때 설정, 길게 누르기 = 씬 메뉴)

### 상단 플롯 타임라인 기본 노출
* 커버 화면에서도 상단 플롯 타임라인 스트립(`S#1 · 프롤로그`, `＋ 장면`)을 기본으로 표시하며, 상단 목차 아이콘으로 언제든 접거나 펼칠 수 있습니다.
* 분기(`IF Branch`) 화면의 블록 표시도 동일한 Sonnet-Create 레이아웃으로 통일했습니다.
