# Civilight 0.2.0

글 쓰는 흐름을 새로 짠 첫 기능 업데이트. 스크립트는 채팅처럼 아래 입력 줄 하나로 쓰고, 인물 · 장소 · 용어는 목록 자리에서 바로 만든다. 게임용 도구는 프로젝트별 스위치 뒤로 들어갔고, 서재와 인물 카드에 3D 보기가 생겼다.
0.1.0 위에 그대로 설치되고 데이터는 모두 남는다.

> 이 버전의 다섯 축: **채팅식 스크립트 입력** · **바로 만들기** · **시나리오 우선 정리(`게임 제작 도구` 스위치)** · **3D 서재와 카드 보기** · **아이콘 버튼**

## 다섯 축

### 채팅식 스크립트 입력
- 아래 입력 줄 하나로 쓴다. `보내기`를 누르면 지금 보는 씬 끝에 블록이 붙는다
- 입력 줄 위에 `리엔 ▾` · `대사 ▾` 칩(화자 · 종류). 보낸 뒤에도 값이 그대로다. 화자가 저절로 번갈아 바뀌지 않는다
- 입력 줄 오른쪽 위에 넣을 자리 `씬 3 끝에`와 `다음 씬` 버튼
- Enter는 줄바꿈. 보내기는 `보내기` 버튼만 한다
- 입력 줄은 6줄까지 위로 자라고, 그 뒤로는 안에서 스크롤하며 커서 줄을 따라간다
- 블록을 누르면 고르기만 한다. 키보드는 뜨지 않는다
- 오른쪽으로 밀면 `고치기 · 이 뒤에 · 종류 · 씬 나누기 · 지우기`, 왼쪽으로 밀면 `◆ 시간 · 참고 · 속성`. 버튼을 눌러야 실행된다
- `고치기`: 블록 글이 입력 줄로 올라오고 `#044 고치기 · 나누기 · 합치기 · ✕`가 보인다. 번호와 ◆는 그대로다
- `합치기`는 앞 블록과 화자 · 종류가 같을 때만. 다르면 `화자 다름` · `종류 다름`
- `이 뒤에`: 한 번 보내면 그 블록 뒤에 들어가고 표시가 풀린다
- 키보드가 떠 있을 때만 도구 줄 `( ) · @ · ◆ · ↶`
- 머리의 `이 씬 · 1-7`과 `씬 n 끝에`는 입력 줄 바로 위 블록의 씬을 따라 함께 바뀐다
- 찾기는 머리 오른쪽 `찾기` 버튼으로 옮겼다
- `선택지`는 한 줄에 하나씩, 두 줄 이상이어야 보낼 수 있다. 화자가 없다

### 바로 만들기
- 목록 맨 위 `＋ 새 인물` 줄. 세계는 탭을 따라 `새 장소 · 새 용어 · 새 세력`
- 누르면 목록 위에 만들기 카드가 뜬다. `취소 · 만들고 열기 · 만들기`. 이름만 있으면 된다
- 화자 · @ 연결 · 장소 고르기 시트에도 `＋ 새 인물` 줄. 찾는 말이 없으면 `＋ '세라' 새 인물`로 바뀌고, 만든 항목이 바로 골라진다
- 같은 방식: 연표 사건, 태그, 관계 종류, 페이지, 캔버스
- 카드는 키보드 위로 올라와 칸이 가려지지 않는다

### 시나리오 우선 정리 · `게임 제작 도구` 스위치
- 프로젝트 설정의 `게임 제작 도구`. 새 프로젝트는 꺼져 있다
- 끄면 숨는 것: 보이스 ID와 ID 형식, `보이스 ID` · `무대 위치` 칸, 연출 큐 칩과 에셋, 인물 `게임 텍스트` 탭, `보이스 18 / 24`, 보이스 점검과 `보이스` 칩, 녹음 CSV · 엔진 JSON 내보내기
- 꺼도 지워지지 않는다. 다시 켜면 그대로 돌아온다. `.civilight` 내보내기에는 늘 들어간다
- 끈 상태의 인물 탭은 `개요 · 말투 · 관계 · 비밀` 넷. 내보내기는 `대본 PDF`와 `.civilight`만
- 연출 · 선택지 블록, 낭독, 블록별 표시 이름은 스위치와 상관없이 늘 있다

### 3D 서재와 카드 보기
- 서재 보기 7가지: `3D 책장 · 표지 회전 · 원고 더미 · 서고 회랑 · 색인 카드 서랍 · 별자리 · 목록`
- 인물 카드 보기 7가지: `부채꼴 덱 · 회전 목마 · 겹친 더미 · 타로 펼침 · 기울어진 벽 · 롤로덱스 · 목록`
- `설정 › 화면`에서 고르고, 머리의 전환 버튼으로 3D와 목록을 오간다. 마지막 보기를 기억한다
- 기기를 기울이면 살짝 따라 움직인다(`기울이면 따라옴`). `애니메이션 줄이기`에서는 멈추고 그 줄도 숨는다
- 숨긴 프로젝트와 인물은 이름 없는 잠금 항목으로 보인다

### 아이콘 버튼
- 뜻이 분명한 버튼은 아이콘만, 덜 분명한 버튼은 아이콘과 짧은 글자, 확인 · 지우기 · 값을 보여 주는 칩은 글자 그대로
- 아이콘만 있는 버튼도 모두 접근성 이름이 있다. 누를 자리는 44 이상

## 영역별 새 기능

### 스크립트
- `낭독`: 한 줄씩 전체 화면으로 읽기. `이전 · 처음부터 · 닫기 · 다음`, 대사 상자를 눌러도 다음 줄. 연출은 ▸ 자막, 메모는 빠짐
- 찾아 바꾸기: 찾기에서 `바꾸기`. 줄마다 체크, `모두 고르기` · `바꾸기 · 12`. 되돌리기 한 번에 전부 돌아옴. 조사는 바꾸지 않고 `조사 확인`만 표시
- 판: 에피소드 ⋯의 `판 남기기` · `지난 판`. 비교 화면에서 지운 줄은 취소선, 바뀐 글자는 상자. 블록마다 `이 판 글로`. 내보낼 때 `내보낸 판`을 자동으로 남김
- 블록별 표시 이름: `속성`의 `이 블록만 · 표시 이름`. 원고에는 `경비병 (하르트)`
- 복선과 할 일: 블록 `속성`에서 `복선 심기`, 다른 블록에서 `다시 언급 · 거두기`. 메모의 `할 일` 체크도 같은 목록
- 용어 후보에 옅은 점선 밑줄. 왼쪽으로 밀어 `참고` › `용어 후보 · 잇기 · 아님`

### 스토리 · 홈
- 홈 머리에 늘 프로젝트 이름
- 홈 `작업` › `할 일 · 복선`: `열림 · 거둠 · 끝냄`, 줄을 누르면 그 블록으로
- 찾기 칩 끝에 `그 밖 ▾`(장소 · 세력 · 사건 · 페이지). `대사`를 고르면 `화자 ▾`
- 점검 센터는 글쓰기에 영향 주는 항목만

### 인물
- 말투에 `한 줄 요약`. 참고 패널에는 요약만 보인다
- 비밀 탭 `이 탭 잠그기`: 열 때마다 지문이나 화면 잠금. 기기 잠금이 없으면 `기기 잠금 필요 · 설정`
- 태그 여러 개인 인물은 태그 묶음마다 보이고, 위 숫자는 한 번만 센다. 태그를 지우면 `쓰는 인물 n` 확인 뒤 태그만 휴지통으로(30일). 되살리면 다시 붙는다
- 개요에 에피소드별 등장 막대와 `마지막 등장`. 정렬에 `오래 안 나옴`
- 항목 편집: `앞으로 · 뒤로` 버튼, 지울 때 `값이 있는 인물 n명`, `템플릿으로 저장`. 템플릿은 설정에서 고치고 새 프로젝트 4단계에서 고른다

### 세계 · 지도
- 용어의 첫 공개는 원고에서 처음 @로 연결한 블록으로 자동. 손으로 정한 값이 있으면 그 값이 우선
- 새 지도는 사진 한 장과 장소 핀

### 캔버스 · 갤러리
- 캔버스 여러 개. 머리의 이름 `▾`로 목록 시트, `새 캔버스`. 홈 `캔버스`는 마지막에 연 캔버스
- 캔버스와 페이지의 ⋯ 메뉴를 같은 순서와 모양으로
- 홀로는 이미지마다 켜고 끈다. 새 이미지는 꺼져 있다
- 카드 진열의 크기와 기울기를 실제 화면에 맞춰, 끌어도 머리와 목록을 덮지 않음

### 서재
- 프로젝트 표지: 갤러리에서 고르거나 새로 넣고 자르기, `빼기`. 서재 ⋯ · 프로젝트 설정 · 홈 머리에서. 숨긴 프로젝트는 미리 보기 이미지를 만들지 않는다

### 라이프 레코더
- `일시정지`하면 마이크를 놓는다. 이어서 말하면 같은 기록에 이어 붙고, `멈추고 저장` 때 순서대로 합친다
- 녹음 중이나 일시정지 중에 앱 안에서 나가면 `정리 안 됨`으로 저장하고 마이크를 놓는다(`기록함에 둠`)
- 앱이 뒤로 가도 녹음은 이어지고 알림이 보인다. 최근 앱에서 지우면 저장하고 마이크를 놓는다

### 디자인
- 시트와 팝업이 아래 바 · 제스처 바 · 키보드와 붙지 않게 고정 간격
- 토스트 길이를 종류별로, 화면을 떠나도 제자리
- 누를 수 있는 것은 눌림 · 꺼짐 상태가 보인다. 홈 `작업`은 목록 줄
- 펼친 화면에서도 한 화면에 아래 바는 하나
- 긴 입력칸은 커서 줄을 늘 화면 안에 둔다

## 이번에 바뀐 동작

- **등급 배지 없음**: `전체 · 15 · 18` 배지, 새 프로젝트의 등급 고르기, 등급별 기본값, `내보내기 표지에 등급 표시`가 빠졌다. 0.1.0의 등급 값은 저장된 채 남고, `이 프로젝트 숨기기` · `화면 캡처 가리기` · `이름 가리기` · `라이프 레코더 연결 가리기`는 각 프로젝트 설정에 그대로 있다
- **레코더는 홈에서만**: 다른 화면 아래 바의 마이크가 빠졌다. 빠른 설정 타일과 홈 화면 위젯, 잠금 화면 녹음 자리와 그 설정 줄도 없앴다
- **이동 점검은 기본 꺼짐**: 거리 · 이동 시간 ▲ 점검은 설정에서 켠다
- **시점은 늘 `최신`으로 열림**: 렌즈 칩은 인물과 세계 머리에만 작게 남았다. 고른 시점은 프로젝트를 닫을 때까지
- **Enter는 줄바꿈**: 0.1.0의 "Enter = 새 블록 · 나누기"는 없다. 블록을 눌러도 고치지 않고 고르기만 한다
- **선택지에는 화자가 없다**: 보이스 ID 꼬리(`_1`)도 없고 녹음 CSV에서도 빠진다. 말하는 줄은 선택지 뒤에 대사 블록으로
- **0.1.0 게임 데이터가 있는 프로젝트는 스위치가 켜진 채 열린다**: 고정 · 버린 보이스 ID, 연출 큐, 에셋, 게임 텍스트, 무대 위치, CSV · JSON 내보내기 기록 중 하나라도 있으면. 한 번만 정하고, 그 뒤는 사용자가 정한 값
- **새 지도는 이미지 지도**: 노드 · 지형 · 스케치 지도 만들기와 편집 도구, 거리, 인물 동선은 숨었다. 0.1.0 지도는 목록에 남고 핀과 함께 보기로 열린다
- **새 이미지는 홀로 꺼짐**: 0.1.0에서 켠 이미지는 켜진 채
- **0.1.0으로 되돌리기는 지원하지 않는다**

## 확인한 것

- 단위 테스트 3,408개 통과, 실패 0, 건너뜀 23(23개 모듈, `CopyLint` · `MotionLint` · `IconButtonLint` 포함). 마지막 수정 뒤에는 고친 모듈(`core:navigation` · `feature:cast` · `feature:library` · `feature:script` · `feature:recorder` · `app`)의 테스트를 다시 돌려 모두 통과했다.
- 에뮬레이터(Android 17, 커버 폭과 펼친 폭, 릴리즈 APK)에서 확인:
  - **0.1.0에서 올리기**: 0.1.0 릴리즈 APK에 데이터를 만든 뒤 0.2.0을 그 위에 설치. 서재 2개 + 숨김 1개, 인물 · 태그 · 용어 · 지도 2개 · 갤러리 4장(홀로 · 자르기 · 회전) · 기록 1개(재생) · 휴지통 2개(30일 남음) 수가 그대로. 게임 데이터 있는 프로젝트만 스위치 켜짐, 끄고 다시 열면 꺼진 채. 고정 보이스 ID, 사용자 항목, 숨김 · PIN · 화면 캡처 가리기, 다크 테마, 손으로 정한 첫 공개 유지. 0.1.0 `.civilight` 두 개(암호 있는 것 포함) 열기, 스위치 끈 내보내기와 다시 열기 왕복. 새로 0.1.0에서 쓴 블록이 0.2.0 스크립트에서 그대로 열림
  - **스크립트**: 기존 프로젝트 · 새 프로젝트 · 새 설치 · 찾기 결과에서 열기, 커버와 펼친 폭. 보내기, 강제 종료 뒤 보내지 않은 입력 남음, `고치기`
  - **레코더**: 녹음 중 마이크 잡음, 일시정지 때 놓음, 이어 말하기와 합친 저장, 뒤로 · 앱 뒤로 보내기 · 최근 앱에서 지우기 · 알림에서 다시 열기, 권한 거부 안내. 어느 경우에도 마이크가 켜진 채 남지 않음
  - **스위치와 정리**: 끄고 켤 때 보이스 · 게임 텍스트 · CSV · JSON이 숨고 돌아옴. 등급 UI 없음, 보호 스위치 동작, 렌즈 칩 위치, 점검 센터, 이미지 지도와 핀, 마이크는 홈에만
  - **바로 만들기**: 인물 · 장소 · 용어 · 세력 · 사건 · 태그 · 관계 종류 · 페이지 · 캔버스 카드, 고르기 시트에서 만들기, 키보드 위 카드
  - **3D 보기**: 서재 6가지 · 카드 6가지를 커버와 펼친 폭에서 열기, `애니메이션 줄이기`에서도. 보기 전환 기억, 기울기
  - 그 밖: 표지, 항목 편집과 템플릿, 찾기 칩, 판 남기기, 할 일 · 복선 목록, 비밀 탭 잠금(기기 잠금 있음 · 없음), 태그 겹침과 되살리기, 등장 막대, 캔버스 여러 개
- 검증에서 막힌 문제 4가지(스크립트 열면 종료, 알림으로 연 뒤 빈 레코더, 기기 잠금을 풀면 비밀 탭이 반응 없음, 쓰이지 않는 지도 설정 두 줄)를 고치고 같은 단계로 다시 확인했다. 앱 크래시와 ANR 없음

## 감춘 것

지운 것이 아니라 숨긴 것이다. 저장된 값은 그대로 남고 `.civilight`에도 들어간다.

- `게임 제작 도구`를 끈 프로젝트의 게임 기능 전부(위 목록)
- 등급 배지와 등급 설정
- 노드 · 지형 · 스케치 지도 만들기와 편집, 거리 계산, 인물 동선, `설정`의 `새 지도 그림` · `지형 만들기 · 글로 설명`
- 이동 점검(켜기 전까지)
- 레코더 위젯 · 타일 · 잠금 화면 녹음 설정 줄
- 숨긴 기능을 가리키던 안내 단계와 도움말 줄(`인물 동선`, `지도 만들기`, 스크립트 `명령 칸`)
- 만들기 카드의 `이미지` 칸(인물 · 장소 · 세력). 이미지는 만든 뒤 카드에서 넣는다
- 연출 큐 고르기 안의 새 에셋 줄. 0.1.0의 `+ 에셋`을 쓴다
- 세계 `기준 사건` 고르기와 용어 `관련` 고르기의 만들기 줄
- 첫 공개를 자동으로 되돌리는 줄
- 인물 목록 태그 칩과 묶음 머리의 색 점
- 등장 막대의 구역 이름과 막대별 접근성 문구
- 3D 보기의 화면 간 공유 전환(지금은 겹쳐 바뀜), 그릴 수 없는 보기를 목록으로 바꾸기
- 서재에서 앞이 아닌 항목의 TalkBack 동작 이름, `기울어진 벽`의 `새 카드` 칸

## 알려진 한계

- 실제 폴더블 기기에서는 아직 보지 못했다. 접기는 에뮬레이터 화면 크기를 바꿔 흉내 냈고, 대부분은 커버 폭에서만 확인했다
- 스크립트의 많은 기능은 단위 테스트로만 확인했다: `낭독`, 찾아 바꾸기, 판 비교와 `이 판 글로`, `복선 심기`, 블록별 표시 이름, 용어 후보 밑줄과 `참고`, `나누기` · `합치기` · 되돌리기, `이 뒤에`, `다음 씬`, 6줄 넘는 입력, 접거나 돌릴 때의 입력. 검증 중 스크립트가 열리지 않아 이 부분을 에뮬레이터에서 돌리지 못했다
- 예시 프로젝트의 읽기 전용 화면, 모듈 안내 투어, 빈 목록의 3D 보기, 숨긴 프로젝트의 표지 · 템플릿 새지 않음, 새 프로젝트 마법사, 0.1.0에서 시점을 골라 둔 프로젝트는 에뮬레이터에서 확인하지 않았다
- 에뮬레이터에 소리와 지문이 없어 녹음 소리, 합친 녹음의 재생 순서, 상태 표시줄 마이크 표시, 지문으로 여는 숨긴 프로젝트는 확인하지 못했다
- TalkBack은 일부 버튼만 들었다. 3D 보기 12가지와 카드 보기의 앞 카드는 읽을 이름이 없거나 확인하지 않았다
- 기울기 방향(펼친 화면 · 가로), 항목이 많을 때의 프레임, 3D에서 돌아간 카드 누르기는 실제 기기에서 볼 것
- 화면에 임시 문구가 남아 있다: `기울이면 따라옴`, 3D 카운터 `n / N`, 스크립트의 `큐 있음` · `2줄 이상` · `씬 처음` · `찾을 말` · `바꿀 말` · `심기` 등
- 외부 서비스가 필요한 기능은 여전히 자리만 있다. Google Drive 백업과 되살리기, 음성 받아쓰기
- 다음 버전으로 넘긴 문제 목록: [`docs/status/qa/0.2.1-backlog.md`](../status/qa/0.2.1-backlog.md)

## 설치

1. `civilight-0.2.0.apk`를 받는다.
2. 설정에서 이 출처의 앱 설치를 허용한다 (출처를 알 수 없는 앱).
3. APK를 열어 설치한다.

0.1.0과 같은 릴리즈 키로 서명했다. 0.1.0을 지우지 말고 그 위에 설치하면 프로젝트, 기록함과 녹음, 설정, 휴지통, 숨김과 잠금, 갤러리가 모두 남는다. 0.1.0으로 되돌아가는 설치는 지원하지 않는다.

## 요구 사항

- Android 10 (API 29) 이상
- 폴더블 권장 (커버 화면과 안쪽 화면 배치). 일반 폰에서도 열린다.
