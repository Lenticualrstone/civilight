# Civilight 0.3.3(Antigravity) · 3D CD 주얼 케이스 · 플로피 CRT · 기계식 힌지 텐션

0.3.2의 추상적 3D 보기 5종을 걷어내고, 실제 물리 오브젝트의 질감과 구조를 정밀하게 모델링한 **3D CD 주얼 케이스**와 **3.5인치 플로피 · CRT 모니터** 보기를 새로 제작했습니다. 또한 `탄성 덱`의 물속 같은 지연을 없애고 기계식 힌지 텐션(Hinge Tension) 물리 감각으로 전면 개선했습니다.

> 이번 버전의 축: **3D CD 주얼 케이스 + 홀로그램 CD** · **3.5인치 플로피 디스크 + CRT 모니터 삽입** · **기계식 힌지 텐션 물리 (`Motion.hingeTension`)**

## 바뀐 것

### 오브젝트 · 3D (신규 2종)
* **CD 케이스 (`CD_JEWEL_CASE`, 기본값)**
  * 투명 폴리카보네이트 주얼 케이스의 좌측 리브 스파인(12개 세로 홈 · 상하 힌지 핀), 어두운 디스크 트레이와 12날 스핀들 로제트, 아크릴 뚜껑의 대각선 반사광과 소책자 고정 클립, 좌상단 카탈로그 라벨 스티커(`CV-01 · 연재`)를 프로시저럴하게 구현했습니다.
  * 내부 CD는 기기 기울기와 회전에 실시간 반응하는 **홀로그램 회절 스펙트럼(`SweepGradient`)**과 미세 데이터 트랙을 렌더링하며, 홀로그램이 켜진 프로젝트는 무지개빛 포일 광택이 강화됩니다.
  * 포커스된 케이스를 탭하면 좌측 힌지 핀(`TransformOrigin(0.13f, 0.5f)`)을 축으로 아크릴 뚜껑이 열리고 홀로그램 CD가 오른쪽으로 미끄러져 나옵니다.
* **플로피 · CRT (`FLOPPY_CRT`)**
  * 상단 **CRT 모니터**: 입체 베젤, 곡면 형광 브라운관, 수평 스캔라인, 코너 비네팅, 기울기 반응 유리 반사 호, 하단 3.5인치 플로피 드라이브 슬롯과 주황색 읽기 LED를 구현했습니다.
  * 하단 **3.5인치 플로피 디스크**: 우상단 45° 모따기 ABS 셸, 브러시드 메탈 슬라이딩 셔터(기울기 반사광 + 홀로그램 셔터 효과), 쓰기 방지/HD 노치, 인쇄 라벨을 구현했습니다.
  * 디스크를 고르면 드라이브 슬롯 쪽으로 들어 올려지며 LED가 점등되고, CRT 화면이 수평 빔 부팅 모션과 함께 해당 프로젝트 정보와 진행 막대(`[██████░░░░]`)를 출력합니다.

### 기계식 힌지 텐션 물리 (`Motion.hingeTension`)
* `core:designsystem`의 `Motion`에 고강성 기계식 디텐트 스프링(`hingeTension`: `dampingRatio = 0.74, stiffness = 920`)과 `crispSpring` 토큰을 추가했습니다.
* `탄성 덱`에서 드래그 지연을 유발하던 `tween` 보간을 제거하고 **1:1 즉각 추적 + 경계 러버밴드 저항 + 노치 디텐트 저항 + 릴리즈 속도 보존 스냅**으로 교체해, 물속에서 끌리는 느낌 대신 찰칵 감겨 붙는 텐션감을 구현했습니다.
