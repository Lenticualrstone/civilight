# Civilight 0.7.3(Antigravity) (Pre-release)

> **장면 구분선 무손실 삭제**, **상단바·플롯 타임라인 밀착 정렬**, 그리고 **Sonnet-Create의 타이포그래피·마크다운·타자기 리빌·인라인 리허설**을 전면 이식한 프리릴리즈입니다.

## 주요 개선 및 새 기능

### 장면 구분선 무손실 삭제 & 안전한 장면 메뉴
* **구분선만 지우기 (블록 보존)**: 장면 구분선 길게 누르기 메뉴에 `구분선만 지우기`를 추가했습니다. 이제 구분선을 지워도 아래 대사·지문 블록이 날아가지 않고 앞 장면 흐름으로 무손실 병합(`SceneActions.merge`, 실행 취소 지원)됩니다.
* 씬 전체와 하위 블록을 함께 관리하는 기능은 `이 씬과 아래 글 모두 관리`로 명확히 분리했습니다.

### 상단바 · 플롯 타임라인 밀착 배치 & 디자인 고도화
* **불필요한 상단 공백 제거**: 스크립트 상단바 높이를 슬림(`66dp`)하게 조정하고 플롯 타임라인을 상단 글래스 바 바로 아래에 밀착 통합해, 헤더와 타임라인 사이에 비어 있던 여백을 없앴습니다. 원고 스크롤 시 본문이 타임라인 글래스 아래로 매끄럽게 흘러 들어갑니다.
* **Sonnet-Create 플롯 타임라인 스타일**: 좌측 `PLOT` 모노 라벨, 활성 씬 카드의 `1.75dp` 액센트 테두리 + 바깥쪽 액센트 글로우 링, 분기 레인의 `⑂` 기호 + 점선 테두리 캡슐, 끝의 점선 테두리 `＋ 장면` 카드를 적용했습니다.

### Sonnet-Create 타이포그래피 · 마크다운 · 시그니처 효과
* **실제 세리프 이탤릭 & 모노스페이스 적용**: 기존 `FontSynthesis.None` 제약을 해제해 **지문(`NARRATION`)은 실제 세리프(명조) + 이탤릭** 무대 지시문으로, **장면 캡슐 칩·`PLOT` 라벨·`//` 주석 메모는 실제 모노스페이스**(`1.1sp` 자간)로 선명하게 구분됩니다.
* **인라인 마크다운 & `@멘션` 칩**: 대사와 지문 안에서 `**굵게**`, `*기울임*`, `~~취소선~~`, `` `코드` ``를 인라인으로 렌더링하며, `@멘션`은 강조색 글자 + 연한 하이라이트 배경 칩으로 표시합니다. 캐릭터마다 에디토리얼 팔레트 색을 부여해 화자 구분을 또렷하게 했습니다.
* **타자기 리빌 & 슬라이딩 탭 & 플로팅 수정 배너**:
  * 새 장면 제목 칩 생성 시 흔들림 없는 **1회 잉크 타자기 리빌**(`TypewriterText`) 적용
  * `[ 대사 | 지문 | 장면 ]` 전환 시 활성 캡슐이 부드럽게 미끄러져 이동
  * 블록 수정(`고치기`) 중 본문 블록 `0.42` 딤 처리 + 입력바 상단 플로팅 글래스 캡슐 배너(`[ ✎ #번호 고치기 · 나누기 · 합치기 · ✕ ]`) 표시

### 원고 위 인라인 리허설 리플레이
* 집중 읽기(Zen) 모드에서 `▶ 리허설`을 누르면 별도 검은 화면 대신 **지금 보고 있는 원고 화면 그대로** 블록이 대화 리플레이처럼 하나씩 등장합니다.
* 다음 대사 직전 하단에 **`[화자명 •••]` 파동 타이핑 인디케이터 버블**이 표시되고, 대사 등장 시 **Android TTS 음성 낭독(화자별 피치 캐스팅) 또는 배속(`0.5× · 1× · 1.5× · 2×`)에 동기화된 타자기 리빌 + 점멸 강조색 캐럿**이 작동합니다.
