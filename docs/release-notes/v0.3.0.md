# Civilight 0.3.0 · 지도 만들기 돌아옴

0.2.0에서 숨겼던 지도 만들기를 다시 열었다. 0.2.x에서는 새 지도를 이미지로만 만들 수 있었는데, 이제 r3 디자인대로 지형 만들기 · 스케치 · 노드 지도를 만들고 고칠 수 있다. 경로와 거리, 인물 동선도 함께 돌아왔다. 숨길 때 코드와 데이터는 지우지 않았기 때문에 예전에 만든 지도는 그대로 열린다.
0.2.4 · 0.2.3 · 0.2.2 · 0.2.1 · 0.2.0 · 0.1.0 위에 그대로 설치되고 데이터는 모두 남는다.

> 이번 버전의 축: **지도 만들기** · **경로 · 거리** · **인물 동선** · **예전 지도 그대로**

## 돌아온 것

### 지도 만들기 (핵심)
- `새 지도`에서 네 가지를 다시 고를 수 있다: `지형 만들기` · `이미지 가져오기` · `스케치 촬영` · `노드 지도`
- `지형 만들기 · 양식`: 땅 비율과 양식(`칸 칠하기 · 다각형 · 상세 지형`)을 골라 만들고, 만든 뒤에도 `단계 다시 만들기`로 단계별로 다시 뽑는다
- `글로 설명`: 글로 적은 지형을 기기 안에서 읽어 지도를 만든다
- 지도 편집 도구 줄: `이동 · 핀 · 영역 · 경로 · 라벨 · 레이어`. 도구는 고른 것에만 동작한다
- 스탬프, 레이어, 지점마다 `보이는 시점`(공개)
- 노드 지도는 노드 편집 화면에서 열린다. 다른 지도는 `지도 보기` › `편집`
- 안쪽 화면에서는 지도 옆 패널을 접을 수 있다(0.2.3의 접는 패널과 같은 방식). 접은 상태는 앱 전체에 기억된다
- 설정 › 지도의 `새 지도 그림` 줄이 다시 보인다

### 경로 · 거리 · 인물 동선 (확장)
- 경로를 다시 그리고 고칠 수 있다. 경로 칩: `A → B · 도보 2일 4시간 · 38 km`
- 축척 막대와 `축척 맞추기` (노드 지도는 축척이 없어 빠진다)
- 지도 그림 칩(`색면 · 먹선 · 색 · 양피지`). 노드 지도에는 없다
- 프로젝트 설정 › `이동 수단` 줄과 화면
- `인물 동선`: 인물 칩, 씬 순서, 경로를 따라가는 선(경로가 없으면 직선 `추정`), `재생`
- `지도에서 고르기`: 이미지 지도만이 아니라 모든 지도에서 빈 곳을 눌러 `새 장소`를 만들고, 핀을 옮길 수 있다
- 안내 `지도 만들기`, `인물 동선 · 장소와 때`가 `도움말 · 안내 다시 보기`에 다시 나온다
- 장소를 지울 때 시트에 `경로 끝 N`이 다시 센다

### 이동 점검은 그대로 설정
- 이동 시간 점검(`▲ 이동 시간`, `◇ 축척 없음 · 점검 못 함`)은 설정의 `이동 점검`을 켰을 때만 돈다. 기본은 꺼짐이다

## 그대로 숨긴 것

- 설정 › 지도의 `지형 만들기 · 글로 설명` 엔진 줄(`기기 안 · 클라우드` 고르기). 클라우드 쪽은 읽는 모델이 아직 없어서 고를 수 없게 했다. `글로 설명` 자체는 기기 안에서 돌아간다. 저장된 값은 남아 있다
- 인물 동선 화면의 마이크는 0.2.0처럼 없다. 녹음은 홈에서만 연다

## 예전 지도 그대로 열림

- 0.1.x · 0.2.x에서 만든 지도(이미지 · 노드 · 지형 · 스케치)와 그 핀 · 영역 · 경로 · 라벨 · 레이어 · 축척 · 이동 수단은 그대로 읽힌다. 0.2.x에서 보기만 되던 노드 · 지형 · 스케치 지도는 다시 고칠 수 있다
- 프로젝트 저장 형식은 바꾸지 않았다. 앱 설정에 지도 옆 패널을 접었는지만 새로 기억한다

## 숨김 · 잠금

- 숨긴 항목이 잠겨 있으면 숨긴 장소를 지나는 경로는 지도에 그리지 않는다. 인물 동선도 그 경로를 따라가지 않고 직선 `추정`으로 잇는다. 그래서 선 모양으로 숨긴 장소 위치가 드러나지 않는다
- 점검 센터의 `◇ 축척 없음` 줄은 숨긴 장소나 숨긴 인물 이름을 잠금 중에 보여 주지 않는다

## 확인한 것

- 단위 테스트 3,575개 통과, 실패 0 (건너뜀 23). 새로 넣은 테스트: 지도 종류별로 열리는 화면과 편집 가능 여부, 새 지도 네 가지, 도구 줄과 안내, 경로 시트(축척 있을 때 · 없을 때), 인물 동선, 편집 진동, 잠금 중 인물 동선이 숨긴 장소를 지나는 경로를 따라가지 않는지, 숨긴 장소가 걸린 `◇ 축척 없음` 줄이 잠금 중 가려지는지, 노드 지도에는 `축척 맞추기`가 안 나오는지, 이름에 ` · `가 든 장소의 경로 줄 제목
- 예전 지도: 0.1.x 형식의 지도 파일(모든 종류와 양식)과 실제 0.1.0 저장소의 지도를 읽어 편집 화면까지 여는 테스트를 통과했다
- 코드 검토: 바뀐 코드 전체를 읽고 찾은 5건을 고쳤다(잠금 중 인물 동선 선이 숨긴 장소를 지나던 것, `◇ 축척 없음` 줄 본문에 숨긴 장소 이름이 나오던 것, 노드 지도에서 `축척 맞추기`가 아무것도 못 고치던 것, 패널을 접은 채 무언가를 골랐을 때 뒤로가기가 선택 해제 대신 편집 화면을 나가던 것, `최근 고친 곳` 경로 줄이 이름 속 ` · `에서 잘리던 것)
- 0.2.4와 같은 릴리즈 키로 서명한 것을 확인했다
- **이번 릴리즈는 에뮬레이터를 돌리지 않았다.** 화면은 보드와 코드로만 맞췄다

## 알려진 한계

- **이번 수정은 기기나 에뮬레이터에서 아직 보지 않았다.** 코드와 단위 테스트, 빌드로만 확인했다. 지도 제스처(옮기기 · 길게 누르기), 패널 접기, `재생` 움직임은 쓰면서 확인한다
- TalkBack으로는 확인하지 않았다
- 이전 버전의 한계: [`v0.2.4` 릴리즈 노트](https://github.com/Lenticualrstone/civilight/blob/main/docs/release-notes/v0.2.4.md)

## 설치

1. `civilight-0.3.0.apk`를 받는다.
2. 설정에서 이 출처의 앱 설치를 허용한다 (출처를 알 수 없는 앱).
3. APK를 열어 설치한다.

0.2.4 · 0.2.3 · 0.2.2 · 0.2.1 · 0.2.0 · 0.1.0과 같은 릴리즈 키로 서명했다. 지우지 말고 그 위에 설치하면 프로젝트, 기록함과 녹음, 설정, 휴지통, 숨김과 잠금, 갤러리, 지도가 모두 남는다. 이전 버전으로 되돌아가는 설치는 지원하지 않는다.

## 요구 사항

- Android 10 (API 29) 이상
- 폴더블 권장 (커버 화면과 안쪽 화면 배치). 일반 폰에서도 열린다.
