# Civilight 0.2.4 · 사용성 개선

0.2.3을 써 본 뒤 나온 요청을 모은 업데이트. 원고 블록 밀기의 좌우를 바꿔 쓰면서 자주 누르는 버튼을 오른쪽(엄지 쪽)에 두었고, `지우기`가 잘 보이게 했다. 블록을 길게 누르면 그 블록에서 할 수 있는 일을 한 번에 모은 메뉴가 뜬다.
0.2.3 · 0.2.2 · 0.2.1 · 0.2.0 · 0.1.0 위에 그대로 설치되고 데이터는 모두 남는다.

> 이번 버전의 축: **블록 밀기 좌우 바꿈** · **`지우기` 잘 보이게** · **블록 길게 눌러 메뉴**

## 바뀐 것

### 블록 밀기 좌우 바꿈
- 블록을 **왼쪽으로** 밀면 `고치기 · 이 뒤에 · 종류 · 씬 나누기 · 지우기`가 오른쪽 끝에 나온다. 쓰는 중에 자주 누르는 버튼이라 엄지 쪽에 두었다
- 블록을 **오른쪽으로** 밀면 `◆ 시간 · 참고 · 속성`이 왼쪽 끝에 나온다
- 읽기 전용 프로젝트와 `고치기` 중에는 왼쪽 밀기가 꺼지고, 오른쪽 밀기만 된다
- 스크립트 안내와 워크스루 첫 장도 `블록을 오른쪽으로 → 시간 · 참고 · 속성`으로 바꿨다

### `지우기` 잘 보이게
- 밀어서 나온 버튼은 다 열리면 모두 또렷하게 보인다. 0.2.3에서는 다섯 버튼 중 `지우기`가 흐린 채로 멈춰 있었다
- `지우기`는 아이콘과 글자 모두 경고색이다

### 블록 길게 눌러 메뉴
- 블록을 길게 누르면 블록이 살짝 떠오르고 나머지 화면은 어두워지며, 옆에 메뉴가 뜬다
- 메뉴: `고치기 · 이 뒤에 · 종류 · 씬 나누기` | `복선 심기 · 다시 언급 · 거두기 · 이 블록만 · 표시 이름` | `◆ 시간 · 참고 · 속성` | `지우기`. 블록 종류와 프로젝트 상태에 따라 없는 줄은 빠진다
- 줄을 누르면 바로 실행된다. 어두운 곳을 누르거나 뒤로가기를 누르면 닫힌다
- 스크롤 중인 원고를 손가락으로 멈춘 것은 길게 누르기로 치지 않는다
- TalkBack에서는 `블록 메뉴`(길게 누르기)와 메뉴의 각 줄이 동작으로 잡힌다

## 확인한 것

- 단위 테스트 3,560개 통과, 실패 0 (건너뜀 23). 새로 넣은 테스트: 밀기 좌우 판정과 열림 · 닫힘, 다섯 버튼이 다 열리면 모두 또렷한지, 길게 누르기 판정, 메뉴 줄 구성과 놓이는 자리, 안내 문구가 실제 밀기 방향과 맞는지
- 코드 검토: 바뀐 코드 전체를 읽고 찾은 4건을 고쳤다(안내가 여전히 `블록을 왼쪽으로`라 읽기 전용 예시에서 따라 할 수 없던 것, 스크롤을 멈추려던 손가락이 메뉴를 열던 것, 떠오른 블록 크기가 두 번 계산되던 것, 메뉴를 닫을 때 블록이 화면이 밝아진 뒤에야 내려앉던 것)
- 0.2.3과 같은 릴리즈 키로 서명한 것을 확인했다
- **이번 릴리즈는 에뮬레이터를 돌리지 않았다.** 충돌 위험도 코드에서만 검토했다

## 알려진 한계

- **이번 수정은 기기나 에뮬레이터에서 아직 보지 않았다.** 코드와 단위 테스트, 빌드로만 확인했다. 밀기 · 길게 누르기의 느낌, 메뉴가 열리고 닫히는 움직임은 쓰면서 확인한다
- TalkBack으로는 확인하지 않았다
- 이전 버전의 한계: [`v0.2.3` 릴리즈 노트](https://github.com/Lenticualrstone/civilight/blob/main/docs/release-notes/v0.2.3.md)

## 설치

1. `civilight-0.2.4.apk`를 받는다.
2. 설정에서 이 출처의 앱 설치를 허용한다 (출처를 알 수 없는 앱).
3. APK를 열어 설치한다.

0.2.3 · 0.2.2 · 0.2.1 · 0.2.0 · 0.1.0과 같은 릴리즈 키로 서명했다. 지우지 말고 그 위에 설치하면 프로젝트, 기록함과 녹음, 설정, 휴지통, 숨김과 잠금, 갤러리가 모두 남는다. 이전 버전으로 되돌아가는 설치는 지원하지 않는다.

## 요구 사항

- Android 10 (API 29) 이상
- 폴더블 권장 (커버 화면과 안쪽 화면 배치). 일반 폰에서도 열린다.
