# Civilight 0.5.2(Antigravity) (Pre-release)

`0.5.2(Antigravity)`는 인물 프로필 화면을 원본 클로드 디자인 아티팩트(`night-manuscript-r3`)의 야간 원고 미학으로 완벽하게 복원한 패치 프리릴리즈입니다.

## 주요 수정 사항
* **인물 상단 히어로 풀-블리드 블러 페이드 복원**: 배경 이미지가 없어도 일반 인물 초상 이미지가 있으면 거대한 네모 카드와 회색 절단 띠 대신, 화면 최상단부터 `22dp` 블러로 배경에 경계선 없이 녹아드는 `FadingHeaderArt`로 표시합니다. (홀로그램이 켜진 초상은 기존처럼 홀로그램 틸트 카드로 표시됩니다.)
* **하단 탭 바 이중 박스 제거**: 무거운 둥근 알약 박스와 선택 캡슐 배경을 제거하고, `BottomGlassBar` 유리 그라데이션 위에 가볍게 떠 있는 가로 스크롤 탭 + `2dp` 강조 밑줄 스타일로 복원했습니다.
