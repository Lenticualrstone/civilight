# Civilight 0.7.1(Antigravity) (Pre-release)

> `0.7.0(Antigravity)`에서 확인된 스크립트 입력바 다크/라이트 색상 반전, 아치 테두리 과강조, 일렁이는 빛 배경 위 블록 불투명 띠, 입력바 우측 씬 번호 중복 표기를 수정한 핫픽스 프리릴리즈입니다.

## 주요 수정 사항

### 아치형 입력바 · 팝업 · 타임라인 다크/라이트 대비 수정
* **다크/라이트 색 반전 해소**: `colors.tint`·`colors.sel` 토큰의 기본 알파를 덮어쓰면서 다크 모드에 밝은 회색·라이트 모드에 진한 차콜이 깔리던 문제를 수정했습니다.
* **선택 탭 가독성 개선**: `[ 대사 | 지문 | 장면 ]` 활성 탭에 `colors.hl` + `colors.acc` 조합을 적용해 다크·라이트 모두에서 또렷하게 구분되도록 다듬었습니다.
* **아치 상단 림 하이라이트 완화**: 과하게 진하던 검은/흰 외곽선을 부드러운 반투명 프로스트 글래스 림으로 조정했습니다.

### 원고 일렁이는 빛 배경 & 입력바 정리
* **블록 불투명 띠 제거**: `TwoSidedSwipeRow`가 평상시(스와이프 미동작)에도 불투명 배경(`colors.bg`)을 그려 일렁이는 빛 배경을 가로지르던 띠 현상을 제거했습니다. 실제 좌우 스와이프 시에만 배경 마스킹이 적용됩니다.
* **중복 `씬 N` 표기 제거**: 상단바와 본문 씬 헤더에 이미 표시되는 일반 작성 상태의 `씬 N` 라벨을 입력바 우측에서 제거해 입력바를 더 깔끔하게 정리했습니다. (`고치기` · `이 뒤에` · 실행 취소/다시 실행 상태는 그대로 유지)
