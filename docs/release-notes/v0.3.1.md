# Civilight 0.3.1(Antigravity) · 구조·안정성·최적화 정비

0.3.0 이후 코드·디자인 아티팩트·기획서 전면 점검 결과를 바탕으로, 실기기에서 발생할 수 있는 치명적 런타임 버그와 보안 허점을 바로잡고 갤럭시 Z 폴드 8(420/480 dpi) 기준의 Material Design 3 구조적 레이아웃과 렌더링·메모리 최적화를 적용한 정비 릴리즈입니다.

> 이번 버전의 축: **스와이프·보안·동시성 치명 버그 수정** · **Z 폴드 8 480 dpi & 힌지 대응(M3 구조)** · **유리 블러·이미지 LRU 캐시/EXIF 최적화** · **언어 표기 및 README 정비**

## 바뀐 것

### 치명적 버그 · 보안 · 동시성 수정
- **스와이프 행 드래그 진동 수정**: `TwoSidedSwipeRow`와 `SwipeTabs`에서 `.horizontalSwipe()`를 `.offset` 앞으로 옮기고 `clipToBounds()`를 적용해, 드래그 시 로컬 좌표계 반전으로 행이 떨리거나 인접 패널을 침범하던 문제를 바로잡았습니다.
- **앱 잠금 우회 차단 및 연타 경합 수정**: `AndroidBiometricGate`가 일시적 하드웨어 오류(`ERROR_HW_UNAVAILABLE`, `ERROR_HW_NOT_PRESENT`)를 잠금 해제로 처리하지 않도록 차단(Fail-Closed)하고, `isPrompting`을 `AtomicInteger` 참조 카운트로 바꿔 연타 시 중간 재잠금을 막았습니다.
- **백그라운드 액티비티 재생성 시 재잠금 보완**: `MainActivity.onStart()`에서 항상 `unlock.onForeground()`를 호출해 만료된 숨김 항목이 잠시 노출되는 빈틈을 없앴습니다.
- **`RefCountedSessions` 동시성 안전화**: 코루틴 취소 시 `NonCancellable`로 참조 카운트를 안전하게 정리하고, 활성 사용자가 남아 있는 슬롯이 제거되어 동일 프로젝트에 `ProjectStore`가 이중 생성되는 경합을 차단했습니다. `slots`를 `ConcurrentHashMap`으로 전환했습니다.
- **R8 릴리즈 안전성 및 예외 방어**: `proguard-rules.pro`의 `NavKey`·`Companion`·`$$serializer` 보존 규칙을 `-keep`으로 강화하고, `PackageCrypto` PBKDF2 반복 횟수 상한(1,000,000) 및 Base64 예외 처리, `HoloLayer` 라이프사이클(`ON_PAUSE`/`ON_RESUME`) 센서 해제, `RecordingRoute` 설정 인텐트 예외 방어, `MineThumb` 사이드이펙트 `LaunchedEffect` 분리를 적용했습니다.

### Z 폴드 8 레이아웃 & M3 구조적 개선
- **힌지(FoldingFeature) 연동**: `CivilightRoot`에서 `androidx.window`의 `WindowInfoTracker`로 `FoldPosture`(`FLAT`/`TABLETOP`/`BOOK`)를 실제 수집해 전달합니다. 내부 가로 화면에서 `PanelSeamButton`이 가로 주름 중앙(`y = 50%`)에 걸치지 않도록 위쪽으로 피해 배치했습니다.
- **상·하 유리 바 인셋 여유 확보**: `TopGlassBar`·`BottomGlassBar`의 최소 높이를 시스템 인셋과 균형 있게 조정해 커버(10:16) 화면과 키보드 표시 시 원고 가시 영역을 넓혔습니다.
- **480 dpi(616 dp) 내부 화면 대응**: 스크립트 `COLUMN_MIN`을 280 dp로 조정해 480 dpi 내부 세로에서도 사이드 패널이 유지되게 하고, 지도 편집 `MapToolbar`에 가로 스크롤과 우측 패널 여백을 적용해 겹침을 없앴습니다. `ViewPicker` 내부 목록에도 `verticalScroll`과 52 dp 행 높이를 적용했습니다.
- **투페인 구조 정합**: 인물 상세 `RecordFrame`이 투페인 내부에서 하단 유리 바를 이중으로 그리지 않도록 수정하고, `CivilightSheetLayout`이 480 dp 미만 좁은 패널 안에서는 중앙 모달 대신 하단 시트로 자동 전환되게 했습니다.

### 시스템 최적화
- **유리 블러(`GlassMaterial`) 제로 할당 및 조건부 녹화**: `OPAQUE`/`SCRIM` 모드에서는 불필요한 `layer.record`를 건너뛰고, `BlurEffect` · `ColorMatrix` · 마스크 `Brush`를 `remember`로 캐싱해 매 프레임 할당을 제거했습니다.
- **공유 이미지 `ImageCache`(LRU) + EXIF 회전 처리 + 비트맵 해제**: `core:ui`에 힙 1/8 상한의 공유 `LruCache`와 EXIF 방향 보정·0 나누기 방어·중간 비트맵 `recycle()`을 통합한 `ImageBitmaps`를 도입하고 표지(`ProjectCover`) 및 인물 슬롯(`SlotImages`)에 적용했습니다.

### 언어 표기 및 문서 정비
- `Cards3dCopy`의 금지어(`넘기기`)와 어미 불일치를 정리(`"밀어서 보기 · 눌러서 열기"`)했습니다.
- 투페인 명령 바 범위 스위치 TalkBack 라벨(`"찾기 범위"`)을 추가하고, `OpenFileScreen`의 잔존 `RatingBadge`를 제거했습니다.
- `README.md`를 `0.3.1(Antigravity)` 기준으로 전면 현행화했습니다.
