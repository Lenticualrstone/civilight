# Civilight 0.1.0

첫 공개 빌드. 시나리오 작성 앱의 뼈대와 주요 화면이 들어 있다.
아직 초기 버전이라 다듬어지지 않은 화면과 자리만 있는 기능이 많다.

## 새 기능

### 스크립트
- 대사, 나레이션, 괄호 지문, 연출 지시, 선택지, 시스템 텍스트, 작가 메모 블록
- 화자 고르기, 씬 나누기와 합치기
- 커버 화면과 안쪽 화면 배치

### 스토리 · 시점 · 때
- 프로젝트 홈, 이어 쓰기, 새 프로젝트의 `시작해 볼 것`
- 시점 렌즈: 지금까지 쓴 곳 기준으로 보기
- 씬의 때와 이동 점검, 점검 센터

### 인물
- 인물 목록과 카드, 태그 필터, 찾기
- 프로젝트별 항목, 비밀 항목
- 관계와 각자의 마음, 관계도

### 세계
- 장소, 용어, 세력 카드
- 용어 첫 공개 기록과 후보 확인
- 연표와 지도

### 캔버스
- 확대와 이동, 노드와 선, 선 라벨
- 페이지, 카드, 이미지 보기

### 서재 · 파일
- 프로젝트 목록, 예시 프로젝트
- 잠금, 등급과 숨기기
- 내보내기와 `.civilight` 파일 열기
- 지우기와 되살리기

### 라이프 레코더
- 녹음 화면과 마이크 권한 안내, 글로 쓰기 대체

### 디자인
- 라이트와 다크 테마, Pretendard 글꼴, 새 앱 아이콘

## 알려진 한계

- 초기 빌드다. 많은 화면이 부분 구현이고, 실제 기기에서 충분히 확인하지 못했다.
- 외부 서비스가 필요한 기능은 자리만 있다. Google Drive 백업과 되살리기, 음성 받아쓰기, 홈 화면 위젯, 빠른 설정 타일, 잠금 화면 녹음, 글로 설명하는 지형 만들기.
- 예시 프로젝트의 내용은 거칠다.
- 제스처 느낌과 글자 선명도 같은 부분은 기기에서 더 봐야 한다.

## 설치

1. `civilight-0.1.0.apk`를 받는다.
2. 설정에서 이 출처의 앱 설치를 허용한다 (출처를 알 수 없는 앱).
3. APK를 열어 설치한다.

릴리즈 키로 서명했다. 이후 버전은 지우지 않고 그 위에 업데이트된다.

## 요구 사항

- Android 10 (API 29) 이상
- 폴더블 권장 (커버 화면과 안쪽 화면 배치). 일반 폰에서도 열린다.
