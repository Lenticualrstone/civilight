# Civilight 0.1.0

첫 공개 빌드. 시나리오 작성 앱의 뼈대와 주요 화면, 갤러리, 화면 전환 모션, 펼친 화면의 패널 비율 조절이 들어 있다.
아직 초기 버전이라 다듬어지지 않은 화면과 자리만 있는 기능이 남아 있다.

> 이 버전의 세 축: **갤러리** · **모션** · **패널 비율**. 셋 다 에뮬레이터에서 직접 확인한 뒤 내보냈다.

## 새 기능

### 갤러리
- 인물 카드와 프로젝트에 갤러리. 목록 · 격자 · 카드 진열 세 가지 보기
- 카드를 고르면 제목 · 설명 · 태그 · 연결된 씬이 함께 보임
- 이미지 정보 고치기, 다른 갤러리로 복사, 순서 바꾸기(`앞으로` · `뒤로` · `맨 앞` · `맨 뒤` · `옮기기`)
- 숨기기와 잠금, 지우기와 되살리기, 프로젝트 찾기에서 이미지 찾기
- 펼친 화면에서는 왼쪽 목록 + 오른쪽 상세 두 칸

### 모션
- 화면 사이 이동, 시트, 목록 ↔ 카드 전환, 이미지 열기에 부드러운 전환
- 모든 모션이 한 곳의 모션 토큰을 따름. 시스템 `애니메이션 줄이기` 설정을 존중

### 펼친 화면 패널 비율
- 두 칸 사이 손잡이를 끌어 `1:2` · `1:1` · `2:1`로 맞춤. 손잡이를 누르면 비율 버튼
- 모듈마다 마지막 비율을 기억

### 스크립트
- 대사, 나레이션, 괄호 지문, 연출 지시, 선택지, 시스템 텍스트, 작가 메모 블록
- 화자 고르기, 씬 나누기와 합치기
- 커버 화면과 안쪽 화면 배치

### 스토리 · 시점 · 때
- 프로젝트 홈, 이어 쓰기, 새 프로젝트의 `시작해 볼 것`
- 시점 렌즈: 지금까지 쓴 곳 기준으로 보기
- 씬의 때와 이동 점검, 점검 센터
- 에피소드와 씬의 `완료 표시`
- 새 프로젝트에서 `단편`을 고르면 구조가 `씬` 한 단계로 시작

### 인물
- 인물 목록과 카드, 태그 필터, 찾기
- 프로젝트별 항목, 비밀 항목
- 관계와 각자의 마음, 관계도

### 세계
- 장소, 용어, 세력 카드
- 용어 첫 공개 기록과 후보 확인
- 연표와 지도, 인물 동선

### 캔버스
- 확대와 이동, 노드와 선, 선 라벨
- 페이지, 카드, 이미지 보기

### 서재 · 파일
- 프로젝트 목록, 예시 프로젝트
- 잠금, 등급과 숨기기
- 내보내기와 `.civilight` 파일 열기
- 지우기와 되살리기, 하루 한 번 휴지통 정리

### 라이프 레코더
- 녹음 화면과 마이크 권한 안내, 글로 쓰기 대체

### 안내
- 첫 실행 워크스루, 모듈별 짧은 안내. `설정 › 도움말`에서 다시 보기

### 디자인
- 라이트와 다크 테마, Pretendard 글꼴(숫자는 고정폭 숫자), 스플래시와 같은 앱 아이콘

## 이번 확인에서 바뀐 동작

- **`완료 표시`가 우선**: 내용이 없는 에피소드나 씬도 `완료 표시`를 하면 `완료`로 보이고 진행 수에 들어간다. 명세 STO-06의 "내용 없으면 미정"보다 앞선다.
- **이미지 제목 · 설명 저장 시점**: 입력하는 동안에는 저장하지 않고, 입력칸을 벗어날 때 · 시트를 닫을 때 · 앱이 뒤로 갈 때 저장한다. 빠르게 입력하면 끝 글자가 사라지던 문제를 이렇게 고쳤다.
- **모듈 안내 단계 정리**: 화면에 대상이 없던 단계(`시점 렌즈`, `연표`, `▲ 이동 시간`)를 뺐다. 도움말 행은 단계 수 대신 `봤음` · `아직 안 봄`만 보인다.

## 확인한 것

- 단위 테스트 2,931개 통과, 실패 0, 건너뜀 23
- 에뮬레이터(Android 17, 커버 폭과 펼친 폭)에서 모션 · 갤러리 · 패널 비율 · 모듈별 안내 · 전체 모듈 열기 확인. 앱 크래시와 ANR 없음
- 마지막 수정 4건은 단위 테스트로만 확인했다: 레코더 안내 중 녹음 일시정지, 프로젝트가 없을 때 서재 안내 1단계 빼기, `단편` 형식의 기본 구조 `씬`, `설명 쓰기`로 연 정보 시트에서 제목이 보이게 하기

## 알려진 한계

- 초기 빌드다. 확인은 소프트웨어 그래픽 에뮬레이터에서만 했고, 실제 폴더블 기기에서는 아직 보지 못했다.
- 지문이나 화면 잠금이 필요한 항목(숨긴 항목 열기, 잠긴 동안 숨긴 이미지 태그 가리기)은 에뮬레이터에서 확인하지 못했다. 단위 테스트로만 확인했다.
- 일부 안내 단계는 대상 행이 화면에 없을 때 쓰는 대체 대상으로만 확인했다.
- 외부 서비스가 필요한 기능은 자리만 있다. Google Drive 백업과 되살리기, 음성 받아쓰기, 홈 화면 위젯, 빠른 설정 타일, 잠금 화면 녹음, 글로 설명하는 지형 만들기.
- 예시 프로젝트의 내용은 거칠다.
- 다음 버전으로 넘긴 외형 문제 목록: [`docs/status/qa/0.1.1-backlog.md`](../status/qa/0.1.1-backlog.md)

## 설치

1. `civilight-0.1.0.apk`를 받는다.
2. 설정에서 이 출처의 앱 설치를 허용한다 (출처를 알 수 없는 앱).
3. APK를 열어 설치한다.

릴리즈 키로 서명했다. 이후 버전은 지우지 않고 그 위에 업데이트된다.

## 요구 사항

- Android 10 (API 29) 이상
- 폴더블 권장 (커버 화면과 안쪽 화면 배치). 일반 폰에서도 열린다.
