# Civilight 0.7.0(Antigravity) (Pre-release)

> **스크립트 에디터 전면 개편**과 **전역 프로스트 글래스(블러) 복구**, 그리고 실험실 기능 **원고 일렁이는 빛 배경**을 담은 프리릴리즈입니다. 기존 6종 블록 및 `.civilight` 프로젝트 파일과 100% 호환됩니다.

## 주요 개선 및 새 기능

### 전역 프로스트 글래스(블러) 복구
* **몰입 상세(`ImmersiveDetailScaffold`) 블러 복원**: `v0.6.1`에서 높아졌던 본문 패널 불투명도를 반투명 프로스트 글래스(`다크 0.56 → 0.64`, `라이트 0.62 → 0.70`)로 되돌리고, 헤더 칩(`LocalGlassSource`)을 가로막던 `OnGlass` 래핑을 정리해 상단 칩이 배경 히어로를 실시간으로 블러 처리하도록 복구했습니다.
* **펼친 화면 `작품 홈` 블러 복원**: 스튜디오 레이아웃 배경에 풀블리드 블러 표지 레이어(`glassSource`)를 복원하고 각 스튜디오 카드에 `GlassSurface.PANEL` 프로스트 효과를 적용했습니다.

### 스크립트 에디터 전면 개편
* **3종 통합 입력(`대사 | 지문 | 장면`)**: 복잡한 6종 시트를 매번 열지 않고 1탭 세그먼트 탭으로 전환할 수 있습니다. (기존 `연출 · 선택지 · 시스템 · 메모` 블록은 그대로 열람·수정 가능)
* **아치형 프로스트 글래스 입력바 (`Docked Glass Arch`)**: 상단 둥근 모서리(`26dp`)와 상단 림 하이라이트가 양쪽 베젤로 자연스럽게 이어지며 원고 위를 실시간 블러 처리(`GlassSurface.DOCK`)합니다. 펼친 넓은 화면에서는 원고 폭(`최대 640dp`)으로 중앙 정렬됩니다.
* **좌측 고정 컨텍스트 슬롯 & 위로 열리는 블러 팝업**:
  * **대사 모드**: 캐릭터 초상화(다중 화자 시 중첩 초상) 탭 → 위로 열리는 블러 팝업에서 1탭 화자 교체, `+` 버튼 또는 길게 눌러 **다중 화자** 토글, 하단에서 전체 인물 열기/추가
  * **지문 모드**: 첨부 아이콘 탭 → `주석 메모 (//)`, `연출 큐 첨부`(게임 제작 도구 ON 시), `@ 항목 잇기` 팝업
  * **장면 모드**: 장면 아이콘 탭 → `빈 장면 바로 만들기`, `지금 씬 장소 · 때`, `씬 목차 열기` 팝업
* **인라인 단축 & 키보드 편의**:
  * `// 내용` 입력 시 출력 제외 작가 메모(`MEMO`)로 자동 저장
  * `---` 또는 `--- 장면 제목` 입력 시 새 장면 즉시 생성
  * 하드웨어 키보드 `Tab` 3모드 순환, `Ctrl/Cmd + Enter` 즉시 전송, 빈 전송 시 흔들림 + 햅틱 피드백, **실행 취소 / 다시 실행(`↶ ↷`)** 지원
* **원고 시각화 다이어트 & 더블탭 빠른 고치기**:
  * 지문 블록의 좌측 배지 영역을 제거해 전체 폭으로 깔끔하게 읽히도록 개선하고, 대사 블록은 동일 화자가 이어서 말할 때 중복 초상·이름을 생략합니다.
  * 다중 화자 대사는 중첩 초상과 `화자 외 N명`으로 표시하며, 블록을 **더블탭**하면 즉시 `고치기` 모드로 진입합니다.

### 플롯 타임라인 · 제로 클러터 IF 분기 · 집중 읽기 & TTS 리허설
* **상단 플롯 타임라인**: 씬 카드(`S#N · 제목`, `대사 N · 약 M분`, 대사 밀도 바) 가로 스트립을 펼친 화면에 기본 표시(커버 화면은 상단 토글)합니다. 씬 탭으로 즉시 이동하고, 길게 눌러 씬 순서(`앞으로 · 뒤로`)나 `장소 · 때`를 편집할 수 있습니다.
* **에피소드 전용 IF 분기**: 분기가 없을 때는 UI에 전혀 노출되지 않으며, 블록 길게 누르기 메뉴의 `다른 전개 쓰기`로 생성합니다. 분기 화면에서 본편 직전 흐름을 흐리게 확인하며 다른 전개를 쓸 수 있고, `본편 채택` 시 기존 본편을 `지난 판`에 자동 백업한 뒤 본편에 반영합니다.
* **집중 읽기(Zen) & TTS 자동 리허설**: 상단 눈 아이콘으로 UI를 모두 숨긴 집중 읽기 모드로 전환할 수 있으며, `낭독 · 리허설` 플레이어에 **자동 재생**, **속도 조절(`0.5× · 1× · 1.5× · 2×`)**, **화자별 피치 캐스팅 Android TTS 음성 낭독**, **글자 동기화 타이프라이터**, **다음 화자 입력 중 표시**를 추가했습니다.

### 실험실 · 원고 일렁이는 빛 배경
* `설정 › 실험실 › 원고 일렁이는 빛 배경`(기본 꺼짐)을 켜면 라이프 레코더의 빛에서 영감을 받은 은은한 일렁이는 빛 레이어가 원고 뒤에 펼쳐집니다. 상단바·아치형 입력바·팝업의 전역 프로스트 블러를 통해 은은한 빛의 움직임을 감상할 수 있으며, `모션 줄이기` 설정 시 정적으로 고정됩니다.
